# Dr. Glow Up

A hyper-casual skin clinic game: wash, squeeze, sculpt and heal a different patient on every level. Press and hold each problem to treat it; the hair brush paints and the laser zaps.

50 levels in 5 chapters. Each chapter unlocks new treatments (dark circles, nose jobs, laser spots, teeth whitening, a wrinkle iron), and level 10 of each chapter is a boss. The level list is generated in `js/config.js`.

Play: https://ellomehllo.github.io/dr-glow-up/

Static site, Canvas 2D, no build step. Run locally with any static server, for example `python3 -m http.server`.
