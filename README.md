# Dr. Glow Up

A hyper-casual skin clinic game: wash, squeeze, sculpt and heal a different patient on every level. Press and hold each problem to treat it; the hair brush paints.

Play: https://ellomehllo.github.io/dr-glow-up/

Static site, Canvas 2D, no build step. Run locally with any static server, for example `python3 -m http.server`.
